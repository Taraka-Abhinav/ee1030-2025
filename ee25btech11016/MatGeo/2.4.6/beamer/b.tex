\begin{frame}{Question}
If $\vec{a} = 5\hat{i} - \hat{j} - 3\hat{k}$ and $\vec{b} = \hat{i} + 3\hat{j} - 5\hat{k}$, show that the vectors $\vec{a} + \vec{b}$ and $\vec{a} - \vec{b}$ are perpendicular.
\end{frame}

\begin{frame}{Solution - Algebraic Approach}
Two vectors are perpendicular if their dot product is zero. We will first simplify the dot product algebraically.
\begin{align}
    (\vec{a} + \vec{b})^T (\vec{a} - \vec{b}) &= (\vec{a}^T + \vec{b}^T)(\vec{a} - \vec{b}) \nonumber \\
    &= \vec{a}^T\vec{a} - \vec{a}^T\vec{b} + \vec{b}^T\vec{a} - \vec{b}^T\vec{b}
\end{align}
Since the dot product is commutative ($\vec{a}^T\vec{b} = \vec{b}^T\vec{a}$), the expression simplifies to the difference of squares:
\begin{align}
    (\vec{a} + \vec{b})^T (\vec{a} - \vec{b}) = \vec{a}^T\vec{a} - \vec{b}^T\vec{b} = |\vec{a}|^2 - |\vec{b}|^2
\end{align}
\end{frame}

\begin{frame}{Solution - Numerical Calculation}
Now, we calculate the squared magnitudes of the given vectors:
\begin{align}
\vec{a} = \myvec{5 \\ -1 \\ -3}, \quad \vec{b} = \myvec{1 \\ 3 \\ -5}
\end{align}
The squared magnitudes are:
\begin{align}
    |\vec{a}|^2 &= (5)^2 + (-1)^2 + (-3)^2 = 25 + 1 + 9 = 35 \\
    |\vec{b}|^2 &= (1)^2 + (3)^2 + (-5)^2 = 1 + 9 + 25 = 35
\end{align}
\end{frame}

\begin{frame}{Conclusion}
Substituting the numerical values back into our algebraic result:
\begin{align}
    (\vec{a} + \vec{b})^T (\vec{a} - \vec{b}) = |\vec{a}|^2 - |\vec{b}|^2 = 35 - 35 = 0
\end{align}
Since the dot product is zero, the vectors $(\vec{a} + \vec{b})$ and $(\vec{a} - \vec{b})$ are perpendicular. Hence, proved.
\end{frame}

// File: vector_ops.c
float check_perpendicularity(
    float ax, float ay, float az, 
    float bx, float by, float bz) {
    
    // Calculate p = a + b
    float px = ax + bx;
    float py = ay + by;
    float pz = az + bz;

    // Calculate q = a - b
    float qx = ax - bx;
    float qy = ay - by;
    float qz = az - bz;

    // Return the dot product of p and q
    return (px * qx) + (py * qy) + (pz * qz);
}
    \end{lstlisting}
\end{frame}

# Define C function argument and return types
c_lib.check_perpendicularity.argtypes = [ctypes.c_float] * 6
c_lib.check_perpendicularity.restype = ctypes.c_float

# Define vectors
a = np.array([5, -1, -3], dtype=np.float32)
b = np.array([1, 3, -5], dtype=np.float32)
p = a + b  # Vector a+b
q = a - b  # Vector a-b

# Call the C function to get the dot product
dot_product = c_lib.check_perpendicularity(*a, *b)
print(f"Dot product from C: {dot_product}")
if abs(dot_product) < 1e-6:
    print("Vectors are perpendicular.")
